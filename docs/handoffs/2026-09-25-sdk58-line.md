## Environment notes for a cloud session

- The container's Playwright wants `chromium_headless_shell-1243`, but only
  `-1194` is installed. Point `PLAYWRIGHT_BROWSERS_PATH` at a scratch directory
  that symlinks `-1194`'s `chrome-linux/headless_shell` to
  `chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`.
  Don't run `playwright install`.
- CI's `app (web-vite)` job once died inside `pnpm install` (an `ENOENT`
  rename under `@sentry/expo-upload-sourcemaps`) before any code ran. One
  re-run passed. If it recurs, it is not a flake to keep re-running.
