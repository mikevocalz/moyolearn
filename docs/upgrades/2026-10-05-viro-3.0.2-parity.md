# Viro 3.0.2 parity and upstream-next coverage

## Release baseline

Moyo moves from the stale `3.0.1-moyo.1` vendor tarball to the public `@reactvision/react-viro@3.0.2` release.

ReactVision 3.0.2 is the current public release and bundles ViroCore 3.0.2. The 3.0.2 line already contains the merged renderer fixes from Viro #545–#550 and ViroCore #397–#399.

## Moyo overlay

The patch-package overlay retains Moyo's existing visionOS/spatial-stylus work and adds these post-3.0.2 upstream-next patches for local validation:

- Viro #555 — active camera mounted between siblings.
- Viro #556 — iOS ObjectDetector view bridge registration.
- Viro #557 — Quest relaunch loop.

These are deliberately kept as patches because they are open upstream PRs, not released Viro features.

## Deferred upstream work

- Viro #554 — function-region pinning. Deferred until its matching ViroCore #404 dependency is available and tested together.
- ViroCore #403 — Core Location starts only when a key/project is configured.
- ViroCore #404 — function-region propagation through cloud-anchor providers.
- ViroCore #405 — Quest plane replay.

These ViroCore changes affect prebuilt native renderer binaries. They should not be faked by changing TypeScript/package versions; they need a renderer rebuild and device validation.

## Acceptance gates

1. `pnpm install --frozen-lockfile` succeeds and patch-package applies cleanly.
2. `pnpm typecheck`, `pnpm lint`, and `pnpm test` remain green.
3. Android: assemble the phone, Quest, and Pico variants.
4. iOS: pod install and build the Viro bridge; exercise ObjectDetector and active-camera remount.
5. Quest: launch/relaunch, camera/input, hit-test, screenshot/recording, and drag regression.
6. visionOS: rebuild pods and run the spatial-stylus path, including disconnect/reconnect.
7. Only after native gates pass should the old vendored 3.0.1 tarball be deleted from `vendors/`.
