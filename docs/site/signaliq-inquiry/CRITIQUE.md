# Inquiry review

The new form uses the existing schools page's tokens and keeps adult intake beside its actual CTA. The status copy describes a saved request without implying an invitation was sent or a person identified from anonymous browsing. Optional sharing starts off. Failure preserves fields and request identity for a safe retry.

The owner inbox names pending, accepted and delivered separately. A subscription link is explicitly insufficient to record a sale. A booking action records a staff decision and tells the operator to send the calendar invitation through the normal scheduling tool. The UI does not expose configuration credentials or student context.

Final production review must verify the live form reaches the deployed Next API, the configured Moyo owner sees its own inbox, and SignalIQ confirms processing. Static screenshots alone cannot establish those facts.
