# Inquiry form direction

Extend the existing schools chapter with a readable adult inquiry form. Preserve the cream/ink palette, typography, spacing tokens, existing illustration and navigation. This is an operational form addition, not a new marketing design system.

The primary action saves a request. The success message must distinguish this from booking a call. Required adult/contact consent and optional SignalIQ sharing are separate controls with no preselected choice. Parent inquiries hide company fields. Avoid student information and unstructured freeform prompts.

Use existing semantic UI primitives, explicit accessible names and keyboard-operable controls. Keep the form in a single column on small screens. In the native Payload admin, lead with delivery state and actual pending/processed distinctions, then expose source actions. Test both data handling and visible error/success behavior before release.
