# Mobbin pass: D02 native shell

Run 2026-11-04 through the Mobbin MCP (`search_screens`). Mobbin offers only
`ios` and `web`; every query used `web`, so these are web layouts read for
structure and mapped onto AppKit controls. Style, palette, type and copy come
from `@acme/theme` tokens and the copy in `apps/desktop`, not from these apps.
Collection: "Moyo Desktop D02-D05",
https://mobbin.com/collections/97689ff1-1bfb-4e1a-9e1e-b7ea28be4254 (private to the account).
