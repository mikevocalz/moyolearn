## React Native macOS limits that shaped the roster

`react-native-macos` `ViewPropTypes.d.ts` exposes `onMouseEnter/Leave`,
`onDoubleClick`, drag and key events, but no right-click. The app compiles
against `react-native`'s types, which have none of the macOS props. Spark's
`onContextMenu` exists only on `SidebarItem` (`spark-ui/src/sidebar/index.tsx:97`).
