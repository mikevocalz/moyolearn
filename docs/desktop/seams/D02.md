## Host menu items D02 re-binds

`V/spark-desktop-host/macos/Main.storyboard` ships About, Preferences… (⌘,), Open… (⌘O),
Close (⌘W), a full Edit menu, View > Show Sidebar (⌃⌘S, `toggleSidebar:`) and
Enter Full Screen, Window and Help. `RNNativeMenu.mm` resolves roles by
selector (`Role()`, lines 12–24) and lets a published item take an existing
item when it targets it.

| Registry command | Menu target | Effect |
| --- | --- | --- |
| `app.settings` | `{ role: "settings" }` | Retitles Preferences… to Settings… and routes ⌘, to the Settings window |
| `file.chooseResource` | `{ role: "open" }` | Retitles Open… and routes ⌘O to the NSOpenPanel |
| (none) | View > Show Sidebar | Left to the host; `SidebarSplitView` answers `toggleSidebar:` and reports through `onSidebarCollapsedChange` (index.tsx:34) |
| `workspace.*` | new root, `placement: { before: { menu: "window" } }` | Workspace menu |

A new item that needs a key another host item holds takes it (`claim:for:`,
RNNativeMenu.mm lines 151–160). D02 avoids that path: every shortcut it sets is
either on the re-bound item or unused by the host.

## Native selection

`spark analyze` after D02 adds `@legendapp/spark-desktop-shortcuts`,
`@legendapp/spark-desktop-windows` and `@legendapp/spark-file-system` to the
included set (`.spark/selection-report.json`). `spark build` rewrites
`package.json` `expo.autolinking.exclude` from that selection on every run
(`spark-cli/dist/build.js` lines 204–227), so the committed list is build output.

## TypeScript

Spark's `ui-search.ts`, `ui-sidebar.ts` and `ui-split-view.ts` re-export paths
ending in `index.tsx`. `tsc` rejects that without
`allowImportingTsExtensions` (TS5097), so `apps/desktop/tsconfig.json` sets it;
`noEmit` is already on in `expo/tsconfig.base`.
