## Restated, with a drift test

`src/auth/roles.ts` restates `ROLE_KINDS` and `DEFAULT_ORGANIZATION_TO_EDUCATION`
(`packages/app/providers/session/role-mapping.ts`) and `MEMBERSHIP_ROLES`
(`packages/auth/src/membership.ts`). Those files import through the
`@acme/auth/membership` workspace alias, which apps/desktop's Metro cannot
resolve. `scripts/auth.test.mjs` reads both files from the repo and fails when
the copies disagree (red-green checked by changing `manager`).
