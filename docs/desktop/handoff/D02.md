## Toolbar (content column, top)

Workspace pop-up (disabled and labelled "Not Signed In" until PR-D04) · Layout
pop-up (Comfortable / Compact) · Find Command (⌘K) search field; "(⌘K)" shows
only when the shortcut module is in the runtime. Matching commands render as an
inline list of rows, label left and shortcut glyphs (⌃⌥⇧⌘ order) right-aligned in
tabular figures. Rows are Pressables because NSButton is fixed at 160×36 by
spark-ui and centers its title. "No command matches "…"." when empty.

## Sidebar

Brand row (mark at 44 pt `targets.adult`, "Moyo Learn" in the `title` ramp
step), then the AppKit source list: Workspace, Resources. Right-click a row:
Open · Choose Resource… · Clear Resource (disabled with no file) · Compact Layout.

## Tokens

Cool dial throughout (adult surface). Spacing `spacingTiers.*.cool`, radius
`radius.control/card`, type `uiRamp` steps `caption`, `label`, `body`,
`title`, `title-lg`. Colors are `semantic.*` light/dark pairs; Appearance
(Match System / Light / Dark) sets `NSApp.appearance`, which switches both the
AppKit controls and the RN `useColorScheme` value the tokens read.

## Accessibility (not yet run against a live window)

Every control is a native AppKit control with an `accessibilityLabel`: the
Workspace pop-up reads "Workspace, sign in to switch" while disabled; the search
field reads "Search commands"; sidebar rows read their section names. The
error notice is announced with `AccessibilityInfo.announceForAccessibility`
because `accessibilityLiveRegion` is Android-only; the sidebar mark is
decorative (`accessible={false}`) so VoiceOver reads "Moyo Learn" once. The
VoiceOver pass, Full Keyboard Access traversal and contrast measurement in both
appearances are open items in the PR body.
