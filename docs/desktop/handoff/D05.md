# Design handoff: D05 Classrooms

SOT-KEYWORDS: desktop handoff d05 classrooms roster states columns

## Who

Tutors and teachers checking who is in a class between sessions; organization
and district staff looking across classes they run. Visible in the Tutor,
Organization and District workspaces only (sidebar row, View > Classrooms ⌘2,
View > Reload Classes ⌘R).

## Layout (content column)

Class list (left, 7 × `section` spacing wide): class name (`label`), then
"Subject · Grade 3-5 · Code ABC123" (`caption`). Selected row on `primary`.
Roster (right): count ("1,204 students", or "37 of 1,204 students" while
filtering, tabular figures) and Filter field; Open Student in Browser… (needs
a selected row) and Copy Student ID; header row; Legend List of fixed-height
rows: Student (left, middle-truncated), Program (left, "—" when none), Status
(left), Enrolled (right, tabular, "Mar 4, 2026").

## States

| State | Trigger | Copy |
| --- | --- | --- |
| loading | request in flight > 300 ms | Loading classes… / Loading roster… |
| empty | no active classes | No classes yet. Classes you create on app.moyolearn.com appear here with their rosters. [Create a Class in Browser…] |
| empty roster | class has no enrollments | No students in this class yet. Share the class code so students can join. |
| filtered-empty | filter matches nothing | No student matches "…". |
| offline | network unreachable | Moyo Learn can’t reach the internet. Check your connection, then reload. |
| permission | 403 (no organization membership) | Classrooms are for organization staff. Ask your organization’s owner to add you. |
| not-found | 404 (archived or not yours) | That class isn’t available any more. It may have been archived. [Try Again] |
| error | other failure | Classes didn’t load. <reason> |
| session ended | 401 | sign-in pane, "You were signed out." |
| overflow | long ids, 10,000 rows | ids truncate in the middle with the full value in the accessibility label; list virtualised |
| destructive | — | none: the API has no roster write |

Desktop has no URL router, so states come from real conditions rather than
route params.

## Accessibility (not yet run live)

Rows are buttons with labels that read every column ("Student usr_…,
Algebra, active, enrolled Mar 4, 2026") and expose `selected`. Keyboard
traversal of the list and VoiceOver are open items.
