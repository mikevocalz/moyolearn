# Design handoff: D03 thermal-state hook and resource fingerprint

SOT-KEYWORDS: desktop handoff d03 thermal state fingerprint nitro

## Thermal state (consumed in PR-D05)

`useShellStore((s) => s.thermalState)` is `"nominal" | "fair" | "serious" |
"critical" | null` (null when MoyoDesktopCore is not in the runtime). PR-D03
renders it only in Runtime Diagnostics. Rules for PR-D05 surfaces:

| State | Whiteboard / OCR behaviour | Visible UI |
| --- | --- | --- |
| nominal, fair | Normal | Nothing |
| serious | OCR worker runs one job at a time; board drops ink smoothing first | Nothing; this is housekeeping, not a user problem |
| critical | OCR queue pauses until the state drops | One quiet line under the capture zone: "Paused while your Mac cools down." No warning color, no countdown |

## Resource fingerprint (D03)

Resources shows the chosen file's name, then one of: "Computing SHA-256…",
"SHA-256 <64 hex>" (selectable, tabular figures), or "Couldn’t compute the
fingerprint: <reason>". The explanation line says the file is read on this Mac
only to compute the fingerprint; the location is not kept and nothing is
uploaded. PR-D05 homework capture uses the same hash to recognise a worksheet
imported twice.
