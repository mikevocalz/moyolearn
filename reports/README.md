# reports/

**Transient. Prunable.** Dated subagent output lands here.

Nothing durable may live in this directory. If a finding matters beyond the phase that
produced it, **promote it into `docs/`** — a numbered section in `docs/MASTER_KNOWLEDGE.md`
or a file in `docs/decisions/` — and leave the report behind as the working trace.

Naming: `{topic}-{date}.md`, or `{topic}-{mode}-{date}.md` where the agent has modes.

Safe to delete wholesale once its findings are promoted. Deleting a report must never lose
a decision; if it would, the decision was in the wrong place.
